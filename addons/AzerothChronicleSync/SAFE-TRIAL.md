# Azeroth Chronicle Sync — Safe trial (WoW Forever)

This addon is an optional, local-only, read-only personal gameplay journal. It is not a bot, does not play the game, and does not access the game process memory, network traffic or protected files.

## Safety first
- Install only the reviewed Lua and TOC files into the normal WoW Forever AddOns folder.
- Never use third-party process scanners, packet sniffers, automation scripts, memory readers, input simulators, or executables to capture gameplay.
- This addon uses WoW's supported Lua interface events and local SavedVariables. There is no in-game web upload or HTTP request.
- The addon cannot guarantee immunity from sanctions; Blizzard's current terms and future policy changes prevail.
- Do not enable any external upload or scheduled file watcher during this first trial. Manually inspect exported data before publishing.
- Avoid posting account identifiers or unreviewed SavedVariables publicly.

## Install on Windows
1. Close World of Warcraft.
2. Download the two files from `addons/AzerothChronicleSync/` in this repository: `AzerothChronicleSync.toc` and `AzerothChronicleSync.lua`.
3. Put both files in `World of Warcraft/_forever_/Interface/AddOns/AzerothChronicleSync/`. The two files must be directly in that folder.
4. Launch Forever and enable **Azeroth Chronicle Sync** in the AddOns list.
5. On Xuthar, type `/acs status`. For an optional diary note, type `/acs note Arrived at the village`.
6. Play normally. The addon reads level changes, completed quest turn-ins, zones, skill-line changes and player status when relevant game events occur.
7. Log out normally or type `/reload` to persist the SavedVariables.

## What is stored
The addon retains the three specifically named characters Xuthar, Thorgar and Aelyndra, their game character names, realm names, levels, XP, regions, professions, a quest completion **counter**, and a limited list of recent events (up to 48 per character) and zones (up to 36 per character). This is not a complete historical archive and it does not capture every existing completed quest automatically. It starts collecting from the moment it is enabled.

Local files are typically found in `_forever_/WTF/Account/<account-folder>/SavedVariables/AzerothChronicleSync.lua` and include an export hex string in `ACS_ExportHex`. Do not share that file without reviewing it. Only export a sanitized JSON generated by your own trusted local workflow after leaving the game.

## Commands
- `/acs status` — report whether tracking is enabled
- `/acs note TEXT` — save a manual note
- `/acs off` — pause tracking and clear the current exported string (not prior local character history)
- `/acs on` — resume tracking

## Trial and rollback
Do an initial short session and verify one ordinary quest completion and a zone transition after logging out. Keep the trial manual; no automatic upload is required. To stop, use `/acs off`. To uninstall, close WoW, remove the addon folder, and optionally remove its SavedVariables file after backing it up.
